### This game is not available in online distribution. This guide will show you how to install NFS Underground 2 from a CD-ROM

1. Buy a physical copy. I got my from [CEX](https://uk.webuy.com/product-detail?id=5030930039608) (this is not a ref link)
2. Buy a CD-ROM reader. NFS UG2 comes on 2 CD-ROMs. I used [Verbatim 43888](https://www.pricerunner.com/pl/45-5240321/Optical-Drives/Verbatim-43888-Compare-Prices)
3. Find some software that will create an .iso file of out a physical CD-ROM. I used Nero Burning ROM but that's just because it was included with my Verbatim reader
